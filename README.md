 D-mart Sales Analytics Dashboard

 Project Overview

The **D-mart Sales Analytics Dashboard** is an end-to-end Data Analytics project developed using **MySQL** and **Tableau**.

The project analyses **10,001 retail transactions** to generate business insights related to:

-> Sales Performance
-> Profit Analysis
-> Product Performance
-> Store Performance
-> City-wise Analysis
-> Category Analysis
-> Customer Payment Behaviour

The objective of this project is to demonstrate practical skills in:

-> SQL
-> Data Analysis
-> Dashboard Development
-> Data Visualization

 Project Objectives

-> Analyse overall Sales and Profit
-> Identify Top 10 and Bottom 10 Products
-> Compare Store-wise Sales
-> Compare City-wise Sales
-> Analyse Category Performance
-> Monitor Monthly Sales Trend
-> Monitor Monthly Profit Trend
-> Analyse Payment Mode Distribution
-> Rank Stores based on Sales
-> Build Interactive Business Dashboards
